ONE-TIME SETUP · IPHONE SAFARI

先把捷徑準備好。

這個網站不直接登入遊戲。需要在 iPhone 內建「捷徑」做一次設定；手機實際相容性仍需你先測試。

01

先做只讀連線測試

在「捷徑」新增一個捷徑，加入「在網頁上執行 JavaScript」，貼上測試程式，再加一個「顯示結果」。

開啟原始碼 ↗

在捷徑詳細設定中開啟「在共享表單中顯示」，接收類型只保留「Safari 網頁」。回到已登入的 .com 遊戲，點分享，執行這個捷徑。

只有結果顯示 supported、gameService、signedIn 都是 true，才繼續下一步。若無法讀到遊戲服務，先停止並把結果回報給製作者。

02

建立正式的操作捷徑

新增另一個捷徑，例如「Poké Console」，依序加入以下四個動作：

  1. 「取得剪貼簿」。
  2. 「匹配文字」，規則填入 ^[0-9]{3,60000}$，輸入選剛才的剪貼簿。
  3. 「在網頁上執行 JavaScript」，網頁輸入必須指定為最初的「捷徑輸入」，不要選匹配文字。
  4. 「顯示結果」，顯示上一步的輸出。
開啟原始碼 ↗

把程式貼入第 3 個動作。在程式最前面的 const digits = 'MATCHED_DIGITS_HERE';，只刪掉 MATCHED_DIGITS_HERE，保留兩邊引號，插入第 2 個動作輸出的「匹配文字」魔術變數。

匹配文字這一步不可省略。它確保插入的資料只能包含數字，不會把任意剪貼簿內容當作 JavaScript。

03

之後，每次都這樣用

在控制台選數值 → 預覽並產生數字指令 → 複製 → 切回已登入的遊戲主選單 → Safari 分享 → 執行「Poké Console」。

只有捷徑回報 ok: true 才代表伺服器回讀確認成功。之後重新整理遊戲。若提示剛儲存過，等提示秒數再試；不要連續重跑。

iPhone 可能會要求你在「設定 → App → 捷徑 → 進階」開啟「允許執行指令稿」，並授權此捷徑存取遊戲網頁。只有在理解並信任這份程式後才開啟；這項權限由你在手機上決定。查看 Apple 官方說明 ↗
